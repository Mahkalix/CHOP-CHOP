La documentation repose sur les documents de cadrage et les maquettes du jeu :

- [Cahier des charges du jeu web solo avec classement mondial](/references/CHOP-CHOP_Cahier_des_charges.docx), version du 2 octobre 2026 : règles, périmètre, propositions et critères du prototype.
- [Diagrammes de cas d’utilisation](/references/CHOP_CHOP_Diagrammes_Cas_utilisation.pdf) : dix pages, une vue d’ensemble et neuf domaines couvrant UC01 à UC54.
- [Maquettes CHOP-CHOP dans Figma](https://www.figma.com/design/5YyQNON3zicZCKuN1CkEH0/Chop-Chop?node-id=0-1) : référence visuelle pour les écrans et l’identité du jeu. Voir [Design et maquettes](./design.md) pour leur application à la documentation.

Le contexte de travail à jour pour l’équipe et les assistants IA est `CONTEXT.md`, à la racine du dépôt. Les conventions de travail sont également résumées dans [Conventions et règles de travail](./conventions.md).

Les copies ci-dessus conservent le format des sources historiques. Leurs propositions restent à valider. Les 54 cas d’utilisation conservent leur valeur de cadrage initial et ne prouvent pas l’implémentation des fonctionnalités. Vérifier le code de la branche utilisée pour connaître l’état réellement disponible.
